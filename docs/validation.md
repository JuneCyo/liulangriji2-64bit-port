# 0.402-port.1 验证记录

本版本于 2026-10-16 构建并进行核心流程测试；2026-10-29 发布前再次核对交付文件及原始资源完整性。

## 游戏与文件身份

- 原版：《流浪日记2：大山深处》，APK 0.402，包名 `org.cocos2d.StrayDiary22`，仅含 `armeabi-v7a` / 32 位 Cocos 1.8.2 引擎。
- 兼容版：`local.straydiary2.port`，版本 `0.402-port.1`，版本号 40201，最低 Android API 23、目标 API 35。
- 原始脚本、场景和图片共 91 个文件，按 `original-assets.json` 在源码、APK 和电脑版 ZIP 中逐个核对 SHA-256。
- APK：ZIP CRC、v1/v2/v3 签名及 ZIP 对齐检查通过；不包含原生库，正式包关闭调试。
- Windows：完整 ZIP 校验通过，包含 EXE 和全部 Web 资源，解压到另一目录后启动通过。

## 核心流程

Windows + Chrome 的隔离浏览器环境与 Android 12 / WebView 101 模拟器均验证：

- 原版标题菜单、静态启动预览交接。
- 新开局、初始天赋选择、开场剧情和进入主界面。
- 进入山谷、探索消耗精力、触发战斗。
- 攻击改变敌人生命值，逃跑返回地图。
- 页面重载后继续游戏，精力及生命值保留。
- 安卓实际 WebView 的触控、Canvas 2D 和 60 FPS 目标配置。

测试未发现 JavaScript 未捕获异常，正式安卓包启动错误日志为空。模拟器宿主进程采用 x86_64，不能据此视为 ARM64 真机性能实测。

## 存档

- 导出与导入包含 `userData`、`adoptData`、`dataCopy`，覆盖进度、成就与回滚快照。
- 错误格式及上一作存档被拒绝，原有进度不变。
- 电脑版导出的 JSON 可在安卓宿主导入并继续游戏；安卓的进度再次导回电脑版后，生命值与成就一致。
- 安卓测试前备份并恢复兼容应用的存档，个人存档不纳入公开代码及下载包。

## 边界

尚未完整通关、覆盖所有结局、所有 Android 版本及所有系统文件选择器。真我 GT Neo3 / Android 14 的实际帧率与启动体验仍待真机验证。60 FPS 是目标设置，不是每台设备的帧率保证。
